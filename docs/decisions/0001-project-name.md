# 0001 — Project name: enterprise-microfrontend-boilerplate

**Status:** Accepted

## Context

The generic phrase "microfrontend-starter" already has 5+ established GitHub
repositories using variations of that name, one with 10.3k stars. A new repo
cannot realistically rank against that for organic search.

## Decision

Name the project `enterprise-microfrontend-boilerplate`. At research time, no
strong open-source competitor existed for the "enterprise" + microfrontend
naming angle.

## Consequences

The name also matches the author's real production experience (corporate
Design System + Micro-Frontends at scale), which supports the credibility of
the "enterprise" claim rather than it being purely a marketing choice.
